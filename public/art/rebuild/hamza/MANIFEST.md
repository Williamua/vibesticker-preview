# B · Hamza 作品站风素材（单屏）

路径：`/workspace/vibesticker/cartoon/cards/rebuild/hamza/`  
拷贝到前端：`public/art/rebuild/hamza/`

## 方向（与 Roof 明显区分）
**单屏编排**：大标题 + 控件岛，少依赖长页滚动章节叙事。  
参考气质：https://www.raomuhammadhamza.tech/ 的超大标题留白与清晰层级，但布局压成一屏可点/可拖。  
视觉：极简米白纸场 + 冲切贴纸作品点缀；不是满幅森林插画墙纸。

## 单屏编排（架构师按此摆）
```
┌─────────────────────────────────────────────┐
│  hero-field（极大留白）                       │
│  ┌ 大标题落左/上（DOM/CSS，勿烧进图）         │
│  │                                           │
│  │          ┌─ 控件岛 ─────────────────┐     │
│  │          │ project-01..04 可点展开   │     │
│  │          │ ui-slider-track + knob    │     │
│  │          │ ui-drag-zone 拖拽上传热区 │     │
│  │          └──────────────────────────┘     │
│  └ 右下/底 可选小松鼠·叶点缀（克制）          │
└─────────────────────────────────────────────┘
```
- 大标题用字叠在 `hero-field` 留白上，**不要**按长卷分章滚动写叙事。
- 项目卡点击 → 同屏展开（overlay / expand-in-place），不是跳长页。
- 滑块、拖拽热区、风格卡均在控件岛内可点可拖。

## 交互（单屏）
1. **项目卡**可点 → 同屏展开详情/预览，再收起。
2. **滑块**：`ui-slider-track` + `ui-slider-knob` 可拖（风格强度 / 数量等参数示意）。
3. **拖拽上传**：文件拖入 `ui-drag-zone` 热区（亦可点选）。
4. 可选：指针靠近时小松鼠躲开、叶轻摇——动效克制，服务控件岛，不做长卷视差森林。
