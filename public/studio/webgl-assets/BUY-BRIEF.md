# 采购对照简报（给 Fab / CGTrader 找模型用）

找到候选后，把链接/截图发视觉总监 + 前端，**对照锁图挑**，不要先买一堆不像的。

## 必买/优先（对齐 workbench）
1. **浮空桌板** — 厚实浅橡木矩形 slab，无桌腿或可去腿；细直纹；约 120×50×4cm 量级  
   搜：`oak tabletop` / `wood desk slab` / `floating shelf thick oak`
2. **桌面切割机** — 像 Cricut Joy/Maker：哑光白、圆角胶囊、前槽、电源键+小灯  
   搜：`cricut` / `vinyl cutting machine` / `plotter cutter white`
3. **标签/热敏贴纸打印机** — 小方盒哑光白，前出纸口；hero 版可带浅木侧板  
   搜：`label printer` / `thermal printer` / `sticker printer`
4. **黄铜/拉丝金台灯** — 圆座 + 细弯颈 + 锥罩  
   搜：`brass desk lamp` / `cone shade desk lamp gold`
5. **小盆栽** — 米陶简盆 + 密叶绿植（非大龟背）  
   搜：`small potted plant ceramic` / `desk plant`
6. **打开的本/速写本** — 横开精装，页可换贴图  
   搜：`open notebook` / `open sketchbook 3d`

## 贴纸
- 建议自做：薄盒 + 我们提供的 albedo（`stickers/`），不必买成品贴纸模型  
- 若买：必须可换贴图、有厚度、可弯曲

## 格式与授权
- 优先 **GLB/glTF**；FBX/OBJ 可转
- 要 **可商用**（网站产品页）
- PBR 贴图齐全更好（albedo/rough/metal/normal）
- 面数：单道具建议 <50k（可再减面）；机器圆角要够，别方块

## 一眼否决
- 冷黑赛博、厚重工业锈蚀、低模方块玩具感、桌腿复杂办公桌、CRT/显示器主道具、泳池/沙漠场景包
