## 1. 相机

| 项 | 建议值 |
|---|---|
| 类型 | PerspectiveCamera |
| fov（vertical） | **35°**（产品棚略长焦，避免广角畸变） |
| 目标点（lookAt） | 桌面中心略偏前缘：`(0, tableTopY, -0.05)` |
| Orbit 高度角（elevation / polar from horizon） | **28°–32°**（略俯视三四分） |
| Orbit 方位角（azimuth） | **约 −35°～−45°**（自左前看向右后，与锁图一致） |
| 相机到目标距离 | 约 **3.2–3.8**（桌长归一化到 ~2.2 后） |
| near / far | `0.05` / `40` |
| 构图 | 桌居中略偏右；上半留空棚负空间；下前景留桌缘与散落厚贴 |

不要第一人称贴桌；不要正俯视。

## 2. 桌（SM_DiningTable）

- 文件：`user-picks/desk/extracted/SM_DiningTable.gltf`
- 原生包围约 **1.05 × 0.80 × 2.67**（X 宽 × Y 高含腿 × Z 长）
- **保留四条腿**，整桌进场景，不做去腿裁切
- 建议变换：
  - position：`(0, 0, 0)`（腿底贴地 / 贴不可见地面）
  - rotation：`(0, 0, 0)`（长边沿 Z；若导入轴向相反则 `y = ±π/2`）
  - scale：统一 **~0.82**，使桌面长边世界约 **2.2**、高度约 **0.66**
- 桌面顶面 Y ≈ `0.66 * scale_y`（按实际包围微调）
- 材质：暖木纹 BC；粗糙度中高；金属度 0；接受接触影

## 4. 灯光与环境

### HDRI（已锁）
- 文件：`user-picks/hdri/batch-all/09.hdr`
- 理由：batch 抽样中亮度最均匀、偏干净白棚（仅 `previews/01.jpg` 有预览图；09 为引擎首选）
- 强度：约 **0.85–1.1**；旋转使主亮区在**右上**（与台灯同侧）
- 色温校正：引擎内套 **≈4000K** 暖白（增益微偏琥珀，忌冷青）

### 场景灯
| 灯 | 建议 |
|---|---|
| 台灯 Bulb | 保留材质 emissive ≈ 0.9；可再乘场景强度 1.2–2.0 |
| 暖 Key | Spot 或 RectArea，色温 4000K，自右上俯射桌面，强度补 HDRI 不足；柔边 |
| Fill | 很弱半球/环境，避免死黑；保持接触影可读 |
| 地面 | 隐形接收影平面（或 ShadowMaterial），桌腿落影清晰 |

### 接触影 / AO
- 每个物件与桌面交界：**清晰柔和接触影**（contact shadow 或 blur 后的 shadow map）
- 桌腿与地面：同样有接触影
- SSAO / GTAO 轻量即可；勿糊成一团

背景：无限暖米 `#F7F3EC`，无墙缝、无地板纹理抢戏。

## 5. 贴纸（材质语言 · 已改锁）

**锁定：平面厚贴（flat thick slab），禁止软纸 3D 弯折/卷边。**

参考：`sticker-style-flat-thick.png`

| 规则 | 说明 |
|---|---|
| 本体 | 正面平面插画；侧面可见**均匀白边厚度**（PVC/厚卡纸 slab） |
| 形变 | **禁止**弯折、卷边、起皱、薄纸撕边 |
| 投影 | 略离桌或贴桌时投下**清晰柔和阴影**；漂浮同理 |
| 打印机 | 吐出同材质厚贴，不是软卷纸带 |
| 散落 | 打印机与速写本之间 **3–5** 张（草莓 / 猫 / 柠檬 / MSB 或 VIBE 等，现有 `webgl-assets/stickers/sticker-*.png`） |
| 本页 | 速写本页 albedo 贴现有 PNG，同样表现厚贴白边，勿做成墨水贴平印 |
| 实现提示 | 薄盒几何（plane + 挤出白边）或双面+侧面环；法线几乎无曲面 |

PNG 源：`webgl-assets/stickers/`（strawberry / cat / lemon / msb / peach / vibe / blossom…）
